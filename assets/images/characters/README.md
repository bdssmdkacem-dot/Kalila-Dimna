## Integration target

The final runtime assets should be transparent-background PNG files:
- lion.png
- crow.png
- dove.png

They should be cropped tightly around the complete animal, kept at high resolution, and prepared for Android without visible white/gray background.

> Note: the current GitHub file connector can write UTF-8 text files but cannot upload binary PNG/JPG files. The source selection is therefore recorded here; the binary image import must be performed through a GitHub binary upload path before these assets can be committed to the repository.
