# 3D Story Animals

The story player now includes a lightweight low-poly 3D animal stage. It uses procedural geometry as a reliable fallback and is prepared for matching GLB assets in this directory.

## Story characters
- lion — الأسد
- bull — الثور
- crow — الغراب
- snake — الحيّة
- monkey — القرد
- turtle — الغَيْلَم
- dove — الحمامة
- hare — الأرنب

## Recommended sources
- Quaternius Ultimate Animated Animal Pack — CC0 1.0; animated 3D animals and glTF/FBX/OBJ/Blend formats.
- Kenney Cube Pets — CC0; 3D animated animal assets.
- Poly Pizza — model discovery catalogue; verify each individual model licence before bundling.

Only assets whose licence permits redistribution in this game should be copied into this directory.
